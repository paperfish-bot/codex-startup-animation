# 更换头像、背景、文字和动态壁纸

本项目的示例图片可以直接使用。更换素材只在自己的项目文件夹中操作；导出工具在浏览器本机处理图片和视频，不会上传文件。

## 先准备画面

- **背景图片**：建议横版 16:9，至少 1920×1080，主体和边缘清楚。
- **背景视频**：Windows 可使用浏览器能播放的 MP4 等视频；建议 MP4/H.264、1920×1080、约 30 帧/秒。视频只用于 Windows 动态背景和动画后半段。
- **头像**：PNG、JPEG 或 WebP 都可以，导出时会居中裁成方形。

如果素材来自 Wallpaper Engine，请先找到真正的图片或视频文件。`preview.gif` 通常只是预览，`project.json` 是项目说明，`scene.pkg` 和 `shaders` 不能直接当本项目的动态壁纸使用。工坊订阅不等于取得公开转载许可；只在自己的电脑使用时，也请遵守素材作者的授权范围。公开发布项目时，请保留本仓库自带的示例素材，或换成你有权再分发的素材。

## 生成背景与粒子线稿

1. 在浏览器打开 [`tools/export-wallpaper-assets.html`](../tools/export-wallpaper-assets.html)。
2. 选择一张背景图片；或者选择一段视频，填写想截取的秒数。两项都选时优先使用图片。
3. 点击“生成背景素材”。下载 `artwork.jpg` 和 `contours.js`，把这两个文件一起复制进项目的 `assets` 文件夹，覆盖同名示例文件。
4. 双击项目根目录的 `index.html` 看画面。线稿与彩色背景应汇聚到同一位置；如果线稿太少或错位，换一帧重新生成两个文件。

**务必用同一画面生成 `artwork.jpg` 和 `contours.js`。** 单独更换其中一个，粒子会汇聚到错误的位置。

## 更换开场头像和文字

在同一个导出工具页面选择头像，点击“生成头像素材”，下载 `avatar.jpg` 并放入 `assets` 文件夹。

要更换文字，在页面底部填写标题、小字和背景字幕，点击“生成文字配置”，下载 `config.js` 并放入 `assets` 文件夹。字幕留空就不显示。`config.js` 是安装后动画的默认文字；浏览器预览页里已保存过的个人设置会优先显示，想看新默认文字，可在预览页点击“恢复默认图片与文字”再“保存并预览”。

## Windows：静态或动态背景

- **静态背景**：`assets` 文件夹里不放 `wallpaper.mp4`。动画结束后显示 `artwork.jpg`。
- **动态背景**：把有权使用的视频复制到 `assets` 文件夹，命名为 `wallpaper.mp4`。仍需按前面步骤从该视频的某一帧生成 `artwork.jpg` 和 `contours.js`。

准备好后，在项目根目录打开 PowerShell，运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\install-seamless-windows.ps1
```

安装脚本会备份上一个已安装版本。平时继续从官方 App 图标启动；只有换素材或更新项目时才重新运行脚本。从动态背景切回静态背景时，先把项目 `assets` 中的 `wallpaper.mp4` 移到别处，再运行安装脚本。脚本会把旧视频移入本机备份目录。

Windows 背景层位于官方页面上方，默认只显示 28% 不透明度，以便保留文字可读性。亮色、细节密集的图片可能使文字变淡；选择对比更清晰的背景通常更有效。浏览器预览页的“保存并预览”只影响那个浏览器，不会同步到已安装的 Windows 动画。

## macOS

替换 `assets` 中的文件后，按 [macOS 使用指南](macos.md)重新构建启动器。macOS 版的背景目前是静态图片；`wallpaper.mp4` 不会成为 macOS 动态背景。
